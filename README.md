# Modélisation 3D - TP4
## Installation
- Créer un nouveau projet Unity (version >= à 6000.2.9f1)
- Importer les fichiers depuis le repo à la racine du projet

### Initialisation manuelle
- Créer un GameObject vide
- Ajouter le script "Off_Loader" au GameObject
- Indiquer le nom du fichier .off à charger sans le .off (ex: bunny)
- Cocher la case "clustered" pour que la simplification s'applique à l'objet
- Il est possible d'augmenter ou de baisser la simplification en modifiant la valeur d'epsilon (cela va modifier la taille des cellules/clusters de la grille)
